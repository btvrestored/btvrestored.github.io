# Повторы: что изменилось
- `scripts/update_repeats.py` читает общий список видео постранично, умеет несколько владельцев, строит встройку, если VK не прислал плеер, и пишет в журнал, что нашёл и что пропустил. У записей прямых эфиров поле VK `live=1` само по себе не означает, что эфир ещё идёт: завершённые записи с длительностью включаются в архив.
- По умолчанию используется числовой ID сообщества `-232964863`, поэтому дополнительные вызовы для `@btv_restored` не нужны. Несколько владельцев задаются через GitHub → Settings → Secrets and variables → Actions → **Variables**, переменная `VK_OWNER_IDS` (например, `-232964863,-123456789`). ID сообществ указываются с минусом. Адреса (`@имя` или ссылка) можно указать вручную, но разрешение адресов зависит от доступных методов VK API; числовые ID надёжнее. В окне `start_gui.bat` то же поле «ID владельцев».
- Скрипт сначала берёт общий список видео. Дополнительное чтение альбомов выполняется только если `video.getAlbums` доступен текущему токену. Если VK возвращает `Application authorization failed`, список видео всё равно обновляется, но записи, доступные только через альбомы, могут отсутствовать. В VK API-схеме `video.getAlbums` помечен как метод для user access token.
- Лимит хранения теперь 48 записей.
- В `repeats.html` убраны подписи «Повтор эфира №X» и «Запись эфира BRIDGE TV: Project Restored.»: показываются только название и дата из VK.
