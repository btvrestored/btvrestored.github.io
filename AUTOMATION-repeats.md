# Повторы: что изменилось
- `scripts/update_repeats.py` читает **все** видео из VK постранично (раньше — первые 100), умеет несколько владельцев, строит встройку, если VK не прислал плеер, и пишет в журнал, что нашёл и что пропустил.
- Несколько владельцев: в GitHub → Settings → Secrets and variables → Actions → **Variables** можно задать `VK_OWNER_IDS` (например, `-232964863,@btv_restored`). Числовые ID надёжнее: ID сообщества указывается с минусом. Для адресов скрипт сначала пробует `utils.resolveScreenName`, затем `groups.getById` и `users.get`. Если тип токена VK запрещает все методы разрешения псевдонима, этот адрес будет записан в журнал как пропущенный, но остальные владельцы продолжат обновляться; если не удалось определить ни одного владельца, `repeats.json` не меняется. В окне `start_gui.bat` то же поле «ID владельцев».
- Теперь просматриваются и все альбомы владельца, а канал `https://vkvideo.ru/@btv_restored` подключён по умолчанию (по умолчанию: `-232964863,@btv_restored`).
- Лимит хранения теперь 48 записей.
- В `repeats.html` убраны подписи «Повтор эфира №X» и «Запись эфира BRIDGE TV: Project Restored.»: показываются только название и дата из VK.
