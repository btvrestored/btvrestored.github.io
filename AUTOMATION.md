# Автоматика BRIDGE TV: Project Restored

## Окно управления (GUI)

Запуск: двойной щелчок по `start_gui.bat` (Windows) или `python3 scripts/gui.py` — страница откроется в браузере. Работает без установки пакетов, доступна только на этом компьютере. В окне три вкладки:
1. **Треклист из проекта** — перетащите EDL, FCP 7 XML, FCPXML, OTIO или текстовый файл; таблицу можно править (имена, время, вид блока, поменять исполнителя и название местами), потом «Сохранить в episodes/».
2. **В эфир** — выбрать эфир, задержку VK Live, время планового старта; кнопки «В эфир», «Ожидание (idle)», «Остановить виджет»; галочка «отправить в git».
3. **Повторы** — обновить `repeats.json` сразу (нужен VK_TOKEN, вводится в поле и нигде не сохраняется).

Файлы проектов: `.drp` (проект Resolve), `.drt` и `.aaf` закрытые, их прочитать нельзя — выгрузите таймлайн: File → Export → Timeline… → FCPXML / «Файлы FCP 7 XML» / OTIO / EDL. Маркеры в файле имеют приоритет, если их нет — берутся имена клипов. Для XML/OTIO можно выбрать видеодорожку (по умолчанию V1).


## Повторы (repeats.json)
- GitHub Action `.github/workflows/update-repeats.yml` каждые 15 минут запускает `scripts/update_repeats.py`.
- Скрипт берёт видео группы VK (`owner_id -232964863`, метод `video.get`), пропускает идущие трансляции и дописывает завершённые эфиры в `repeats.json` (новые сверху, максимум 24).
- Страница repeats.html читает `repeats.json`; если он не загрузился — показываются плееры, вшитые в HTML.
- Где взять `VK_TOKEN`: зайдите на id.vk.com/business → «Приложения» (или dev.vk.com → «Мои приложения»), создайте приложение (тип — сайт/standalone, название любое), в его настройках найдите поле **«Сервисный ключ доступа»** и скопируйте. Это токен приложения: он годится для открытых методов API, срок действия не ограничен, храните только в секретах и никому не показывайте. Если `video.get` вернёт ошибку доступа к видео группы, создайте токен сообщества (Управление → Работа с API → Ключи доступа, права «Видео») и подставьте его в тот же секрет.
- Настройка секрета: репозиторий → Settings → Secrets and variables → Actions → New repository secret, имя `VK_TOKEN`. Первый запуск — вкладка Actions → Update repeats → Run workflow.
- Названия берутся из заголовков видео во VK, поэтому называйте эфиры при публикации.

## Треклист по таймкодам (DaVinci Resolve → OBS)
Эфир монтируется заранее, idle (ожидание) в OBS идёт отдельным файлом, поэтому в таймлинию эфира `[ожидание]` ставить не нужно: время эфира отсчитывается от его первого кадра.
1. В Resolve ставите маркеры на начало каждого клипа, имя маркера — `Исполнитель — Название` (метки блоков — ниже).
2. Экспортируете маркеры в EDL: в Media Pool правый клик по таймлинии → Timelines → Export → Timeline Markers to EDL (по руководству Resolve 18.6; в Resolve 20 пункт должен быть там же, а если нет — поищите в File → Export). Имя маркера или его заметка (Notes) — подойдёт любое: скрипт берёт имя, а если оно стандартное «Marker N» — заметку.
**Без маркеров (обычный экспорт таймлинии):** подойдёт и «EDL-файлы» из File → Export → Timeline… Скрипт сам определит, что маркеров нет, и возьмёт имена клипов: клипы короче 30 с (заставки, склейки) пропускаются, «Рекламный блок»/`adsstart` становятся рекламой, имена очищаются от «(1080P_HD)», «(Official Video)» и т. п. Свои правила: `--rules rules.json` с содержимым вроде `[["ночноевещание|rock-party-time", "promo"], ["EBU Color", "tech"]]` (виды: ad, promo, wait, tech, skip, music); порог — `--min-track 45`. Имена вида «Название - Исполнитель» и «мусорные» имена файлов скрипт не исправит — он напечатает «⚠ проверьте имя», поправьте их в получившемся json вручную.

3. `python3 scripts/make_tracklist.py markers.edl episodes/ep01.json --title "Эфир 1" --duration 01:12:30`
   (fps по умолчанию 25, начало таймлинии 01:00:00:00; другие значения — `--fps`, `--start-tc`). `--duration` — длительность эфира: по её окончании сайт снова покажет «ожидание». Вместо EDL можно дать текстовый файл со строками `00:03:41 Артист — Название`.
4. Перед эфиром, пока в OBS идёт idle: `python3 scripts/go_live.py --idle --push` — сайт показывает «Ожидание эфира» с шуткой.
   Можно заранее задать время старта: `python3 scripts/go_live.py episodes/ep01.json --at "2026-10-06 20:00" --push` — до старта сайт показывает ожидание и отсчёт «До начала» (таймер Snaz в OBS при этом живёт сам по себе, сверяйте время).
5. Когда в OBS реально стартует файл эфира: `python3 scripts/go_live.py episodes/ep01.json --push` (старт = сейчас). Задержку VK Live компенсирует `--offset 15`.
6. После эфира сайт сам вернётся к «ожиданию» (если задан `--duration`). Полностью спрятать виджет: `python3 scripts/go_live.py --stop --push`.

Ограничения: если эфир в OBS ставили на паузу, перематывали или добавляли вставки, которых нет в маркерах, время «уедет». Сайт обновляется через минуту после push (GitHub Pages).

## Служебные блоки с юмором
Имя маркера в Resolve начинается с метки: `[ожидание]`, `[реклама]`, `[заставки]` (или `[анонс]`), `[техника]` (или `[tech]`; английские: wait, ad, promo, tech).
- `[техника]` без текста — сайт покажет случайную шутку («А мы на север ушли, вернёмся через 10 минут» и др.), с текстом — ваш: `[техника] Ушли за кабелем`.
- Служебные блоки не попадают в «Недавно играло». Список шуток — в `index.html`, объект `KIND` (там же можно добавить свои).

## Ручной режим (tracklist.json)
`{"updated":"2026-10-06T09:00:00Z","now":{"artist":"…","title":"…"},"history":[{"artist":"…","title":"…"}]}` — виджет скрывается, если `updated` старше 15 минут.
